# Rocky – The Rockefeller Christmas Tree: The Little Tree with Big Dreams
### Interactive Scope of Work (SOW) & 2D Animation Production Proposal

A comprehensive, interactive Scope of Work (SOW) and commercial production platform engineered by **Neo Gen Technologies** for client **Jennie E. Nicassio** (Nieje Productions) for the screen adaptation of *"Rocky – The Rockefeller Christmas Tree: The Little Tree with Big Dreams"*.

---

## 🌟 Overview & Key Features

- **Dual-Track Production Strategy:**
  - **Track A (Prestige Broadcast & Festival):** 16:9 Cinema 4K UHD @ 24fps proof-of-concept pilot and full 40-minute screenplay feature special.
  - **Track B (Viral Short-Drama Series - Recommended):** 30 serialized 9:16 vertical episodes (60–90s each) tailored for YouTube Shorts, TikTok, and Instagram Reels leading up to Christmas.
- **Narrative Beat Architecture:** 33-beat screen adaptation breakdown cross-referenced with the registered screenplay and published children's book.
- **Voice-Over (VO) Breakdown & Casting Matrix:** Character dialogue metrics, studio recording allocations, indie multi-voice ensemble packages, and hourly add-on buffers.
- **YouTube Channel Management Engine:** Strategic rollout calendar, A/B thumbnail testing, Christmas SEO discoverability, and pinned funnel to Amazon book sales.
- **Interactive Budget & Scope Configurator:** Real-time scope customization with live budget calculations, itemized quote generation, and 25% milestone payment breakdowns.
- **Client Digital Sign-Off Portal:** Direct digital signature pad and formal authorization submission system.
- **Executive Print / PDF Formatting:** Custom print styling that converts the dark luxury interface into an executive white-paper layout ready for physical signing or archival.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/faxingberling1/Rocky-TheRockefellerChristmasTree.git
cd Rocky-TheRockefellerChristmasTree

# Install dependencies
npm install

# Start the local server
npm start
# or
node server.js
```

The interactive application will be available at:
`http://localhost:3000`

## 🛠️ Technology Stack

- **Backend:** Node.js, Express 5, File-based JSON Persistence (`quotes_storage.json`, `approvals_storage.json`)
- **Frontend:** Vanilla HTML5, Modern CSS3 (Glassmorphism, CSS Grid, Responsive Design), Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (`Outfit`, `Cinzel`, `Inter`)
- **Assets:** Extracted high-resolution book cover typography, character artwork, and Rockefeller Center Christmas Tree backgrounds.
